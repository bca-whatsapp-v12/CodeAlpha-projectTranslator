# Chaitra's Language Translator - CodeAlpha Project

A simple Flask web app that translates text between Hindi, Kannada and English.

## Features
- Translates Hindi, Kannada, English
- Clean responsive UI
- Free MyMemory API
- Built for BCA Final Year Project

## How to Run
1. pip install -r requirements.txt
2. python app.py
3. Open browser at http://localhost:5000

## Tech Stack
- Python Flask
- MyMemory Translation API
- HTML/CSS
